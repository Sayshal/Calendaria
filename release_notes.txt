## New Features

- End Hold world setting on the Cinematics tab keeps the final date on screen before the cinematic closes

## Bug Fixes

- Calendaria windows under the WFRP 4e system with the dark theme no longer pick up WFRP styling; headers, content padding, inputs, tabs and footer buttons use core Foundry styling
- Cinematic sky settles toward night when days pass too fast for a readable day-night cycle, instead of flashing between day and night
- Cinematic slider number inputs clamp to their own slider range; Panel Duration no longer clamps to 100-5000
- Discord links in the settings footer and Module tab point to a working server invite
- Moon phases no longer drift on calendars with a non-zero year zero that use cycle-reset anchors

## Changes

- Cinematic time skip playback eases in and out, starting and ending slowly
