## Breaking Changes

- getAllMoonPhases now returns one entry per moon slot with moonIndex and moonName, with hidden moons returned as null for players
- Legacy note repeat modes (daily, weekly, monthly, yearly, moon, seasonal, and the rest) are retired; notes still storing one load as non-repeating, with condition trees and computed events as the only repeat systems
- One-time data migrations from pre-1.2.0 versions are removed; worlds on very old versions should update through 1.2.x before 1.3.0
- The per-user moon phase toggles for the mini calendar, big calendar, and chronicle were removed in favor of the world-scoped setting

## New Features

- Added variable-length weeks: a calendar can define a repeating cycle of weeks with differing weekday counts, set up in a new week cycle table on the editor's weekdays tab
- Calendar grids (big, mini, secondary, and print) render cycle weeks with blank cells for absent weekdays, and multi-day event bars stay visible across skipped days
- When a week cycle is active, the editor disables the per-month starting weekday and week-start selectors, since the cycle controls weekday flow

## Bug Fixes

- Announcement, reminder, release, and forecast chat cards no longer render unreadable text and links on light themes
- Saving HUD settings no longer throws a ReferenceError
- Season-change macro triggers now fire when the active season changes
