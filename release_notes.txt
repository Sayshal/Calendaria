## Breaking Changes

- Calendaria now requires the 3DS:ATLAS module, which provides shared theming, logging, localization, and update notices.
- Theme selection, custom themes, and the GM force-theme option now live in ATLAS's Theme Config; the old in-app theme editor and forced-theme settings are gone, and your existing theme choice and custom themes migrate into ATLAS automatically on first load.

## Changes

- Bug reports run through the ATLAS troubleshooter, which now attaches the active calendar, its override settings, and every note on it as JSON for support.
- Bumped the bug-report template's version placeholders to Foundry 14.364 and dnd5e 6.0.0.
- Removed the bundled localization files; translations now come from the required 3DS:ATLAS module.
- Standardized the GitHub issue templates on canonical type labels and added a Discord contact link to the issue chooser.
