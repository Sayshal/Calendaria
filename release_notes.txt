## Bug Fixes

- /calendar now shows temperatures in the world's configured unit
- /calendars now marks the active calendar
- /datetime with no argument now outputs a readable date and time
- /note no longer assigns an event category with no matching preset
- /note now shows only a no access warning to players without Add Notes permission
- A forced HUD now respects the scene's Hide HUD for Players flag
- A running stopwatch now keeps its current run time across save, close and reload
- A secondary calendar now reopens under the new calendar's window id after switching calendars, fixing date links
- API createNote no longer leaves an orphan journal entry when page creation fails
- API createNote now falls back to the first category preset's icon and color when none are passed
- API createNote now keeps explicitly passed allDay, icon, color, visibility, displayStyle and reminder fields instead of replacing them with preset defaults
- API time-until, daytime and preset helpers now use the active calendar's day length instead of 24 hours
- API timeSince now accounts for year zero and no longer returns NaN
- Calendar and importer ids now transliterate non-ASCII characters instead of dropping them
- Calendar and note import error messages are now localized
- Calendar componentsToTime now treats `day` as day-of-year when month and dayOfMonth are omitted
- Calendar editor Reset now defers festival note deletion until the calendar is saved
- Calendar import now creates the undated events shown in the preview
- Calendar import now keeps the source current date when no notes are imported as notes
- Changing a moon color in the calendar editor now updates its phase slider and icons
- Changing the FXMaster Above Darkness or Weather FX Levels scene flags now refreshes weather effects
- Checkbox check marks are now centered
- Chronicle Show to All can no longer be closed by players
- Chronicle season banners and wind phrases are now localized
- Clearing a date or time format in the calendar editor now falls back to the default format instead of leaving stray braces
- Climate zone Saturation hint now describes the hue tint strength
- Compact on Encounter Creation now compacts the HUD when the encounter is created instead of when combat starts
- Custom presets saved from the weather picker now keep the base preset's HUD effect
- Cycle note conditions now match the stage the calendar displays
- Date validation now respects the calendar's hours per day and minutes per hour
- Deleting or reordering seasons now remaps season macro triggers to the correct season
- Editing a brightening weather preset now keeps its negative darkness penalty
- Equivalent-date labels now show localized calendar names
- Forcing Time Keeper, Stopwatch, BigCal or Sun Dial for all players now opens it on player clients without errors
- Hide Moons From Players now also hides phase names from the moon format token
- Hide on encounter no longer brings the widget back when an unstarted encounter is updated
- MiniCal and BigCal block visibility resets now include Show Selected Date in Header, and the MiniCal reset also includes Show Time
- MiniCal no longer crashes for players when every moon is hidden from them
- Moon phase, full moon, convergence and eclipse API results are no longer offset by the year on calendars with a non-zero year zero
- Note enrichers now hide secret notes from players
- Notes added from the HUD, Note Viewer, Sun Dial or a calendar day's Add Note menu in the last hour now roll their end time into the next day
- Per-moon eclipse condition presets now fire only on that moon's eclipse
- Player /setdate and API date jumps now land on the requested day and year instead of day 1 in the wrong year
- Player Set Date with Skip Event Triggers no longer fires events on the GM
- Player-set weather now keeps wind, precipitation, period and FX overrides when relayed to the GM
- Players can no longer change world time by dragging or typing in the Sun Dial without Change Date/Time permission
- Players with Change Weather can now Save as Custom Preset from the weather picker
- Players with Change Weather can now change the Scene Zone in the weather picker
- Randomized moons now cache phases per moon and refresh after cycle edits instead of sharing or showing stale phases
- Reset Position buttons on the BigCal and Stopwatch settings tabs now work
- Resetting a forced HUD position as a player now moves it without a warning
- Reveal Intermediate Days now reveals the rewound days when time moves backwards
- Saving Scene Config no longer overrides the global Default Brightness for that scene
- Saving a climate zone no longer stores hue 0 and tints scenes red at dawn, dusk and night
- Saving a custom weather preset no longer stores hue 0 and tints scenes red
- Scene Integration reset now includes Darkness Sync All Scenes and both ambience intensity settings
- Settings panel changes no longer reset the HUD sticky position lock and remembered increment
- Several settings no longer show raw keys in reset confirmation and now appear in Recently Changed
- Skip Fogged Months no longer skips a month whose last days fall inside the reveal radius
- Solar and lunar eclipse conditions now check every moon on a day, not only the first eclipsing one
- Stopwatch dial text, ticks and numerals now use theme colors and are readable
- Stored weather for a new day is no longer ignored on calendars with a non-zero year zero
- Sun Dial format controls now show a live preview and the Custom format box
- Sun Dial no longer piles up window listeners on every redraw
- Switching the active calendar now updates connected player clients without a reload
- The Condition Builder now keeps root OR groups on open and save instead of converting them to AND
- The GM now rejects socket time and weather requests from users who lack Change Date/Time or Change Weather permission
- The HUD no longer stays in compact combat mode after viewing a scene with no combat
- The MiniCal notes panel date now uses the Note Date display format
- The Stopwatch Start/Pause keybind and API start no longer throw when the stopwatch cannot open
- The Week time step now uses the calendar's days per week, and Month and Season use the current month and season length
- The Weekly Almanac no longer lists moon phases when Hide Moons From Players is on
- The Weekly Almanac now localizes bundled moon names
- The forecast enricher's today line now uses the current weather's zone, name and temperature consistently
- The next full moon enricher now reports no full moon found instead of No convergence found
- The note sheet has compact tabs, uppercase fieldset legends and a full-width editor again
- The player-view API forecast requested by a GM now applies forecast variance
- The stopwatch face now renders at its real size instead of a blank, blurry circle until resized
- Time Keeper mouse wheel no longer selects Month on monthless calendars
- Toolbar Apps checkboxes no longer save a null entry
- Trigger on Rest setting hint now says any rest plays the cinematic, matching short and long rests
- Upcoming note occurrences now start from the current date instead of skipping a year
- Users who lose stopwatch permission no longer get a no access warning on every load
- Weather Units reset now also resets Wind Speed Unit
- Weather preset effect macros now run for auto-generated, forecast, period and catch-up weather
- Weather set or generated for another zone no longer changes the current scene's sound and FX
- Widget tooltips containing double quotes no longer break widget HTML
- [yearInEraOrdinal] no longer prints a bare "th" when no era applies

## Changes

- API docs no longer list the widget onDetach callback, the showChronicle theme option or an invalid createNote displayStyle default
- Clock lock is now GM-only, and players shift-clicking the clock button get a warning instead of a local flip and error
- Delete Notes now lets players delete owned notes they did not author, and authors can always delete their own notes
- The Assistant GM column is removed from the Permissions tab since Assistant GMs already have full GM access
- The Chronicle Collapsible entry depth is removed, and existing Collapsible selections fall back to Excerpts
- The W format token now counts week numbers by calendar grid row
- The unused weather preset chance value is removed, and a migration strips it from custom presets
